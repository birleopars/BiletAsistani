# Bilet Asistanı Passo V2 – deneysel kaynak

**APK değil, Android kaynak projesi.** GitHub Actions ile debug APK derleme yapılandırması içerir. Derleme ve gerçek Passo çalışması doğrulanmadı.

İşlevler: Erişilebilirlikte etiketli 11. kategori (yoksa 10. kategori) kontrolünü tıklamayı dener. Ekranda `Koltuk Listesi (1/1)` görünürse erişilebilir `Devam Et` düğmesini tıklar. Güvenlik doğrulamasında durur. Sepet onayı görünürse alarm verir. Ödeme yapmaz.

**Önemli:** Koltuk haritasındaki beyaz koltuklar görsel çizimse bu sürüm onları algılayıp seçemez. Blok seçimi de uygulanmadı. Sepete ekleme garanti değildir. Erişilebilirlik izni güçlüdür ve uygulama güvenilir kaynaktan kurulmalıdır.
